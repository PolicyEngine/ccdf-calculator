# Data contract

All files live in `public/data/` and are generated by `scripts/`. The
frontend reads them with `fetch(`${NEXT_PUBLIC_BASE_PATH}/data/...`)`.

## `metadata.json` (from `precompute.py`)

```jsonc
{
  "policyengine_us_version": "1.824.7",
  "year": 2026,
  "income_steps": [0, 1000, ..., 200000],        // 201 annual earned-income points
  "charge_levels": [1000, 1500, 2000, 2500, 3000], // provider charge, $/child/month
  "default_charge_index": 1,                       // $1,500
  "adults_range": [1, 2],
  "child_structures": {
    "infant":    {"ages": [1],       "hours_per_day": [8]},
    "preschool": {"ages": [3],       "hours_per_day": [8]},
    "school":    {"ages": [7],       "hours_per_day": [3]},
    "two":       {"ages": [3, 7],    "hours_per_day": [8, 3]},
    "three":     {"ages": [1, 3, 7], "hours_per_day": [8, 8, 3]}
  },
  "assumptions": {
    "monthly_charge_per_child": 1500, "days_per_week": 5,
    "attending_days_per_month": 22, "weekly_hours_worked": 40,
    "provider": "state default provider type (a licensed center) at the base quality tier"
  },
  "states": [{"code": "AK", "name": "Alaska", "program": "Child Care Assistance Program (PASS)", "county": "ANCHORAGE_MUNICIPALITY_AK"}, ...]
}
```

## `{ST}.json` (from `precompute.py`), one per state

```jsonc
{
  "state": "IL", "year": 2026,
  "structures": {
    "1_two": {                       // key = `${adults}_${structureKey}`
      "subsidy":  [[...201 numbers], ...5 rows],  // [chargeIndex][incomeIndex], $/month
      "copay":    [[...], ...],                    // $/month, already converted from weekly/daily
      "eligible": [[...], ...],                    // booleans
      "fpg": 27320.0,                              // annual federal poverty guideline for this unit
      "smi": 107637.6                              // annual state median income for this unit size
    },
    ... 10 keys: {1,2} x {infant, preschool, school, two, three}
  }
}
```

Interpretation: `subsidy` is what the state pays the provider each month for
the household's children; `copay` is what the family pays the provider;
the family's remaining out-of-pocket cost is `charge * children - subsidy`
(which equals the copay whenever the charge is under every cap).

## `state_inputs.json` (from `build_state_inputs.py`)

```jsonc
{
  "year": 2026,
  "states": {
    "IL": {
      "code": "IL", "name": "Illinois", "program": "Child Care Assistance Program",
      "main": "il_ccap",                 // monthly subsidy variable (SPM unit)
      "copay": "il_ccap_copay",          // copay variable
      "copay_entity": "spm_unit",        // or "person" (then sum over children)
      "copay_factor": 1,                 // number, or "days" (multiply by attending days/month)
      "eligible": "il_ccap_eligible",    // SPM-unit bool, or null (use subsidy > 0)
      "county": "COOK_COUNTY_IL",
      "copay_label": "...", "main_label": "...",
      "outputs": ["child_care_subsidies", "il_ccap", "il_ccap_copay", "spm_unit_fpg", "hhs_smi", "il_ccap_eligible"],
      "inputs": [                        // state-specific user inputs
        {"name": "childcare_provider_type_group", "label": "...", "entity": "person",
         "type": "enum", "default": "DCC_SACC",
         "options": [{"value": "DCC_SACC", "label": "Licensed day care center ..."}, ...]},
        {"name": "il_ccap_enrolled", "label": "...", "entity": "spm_unit", "type": "bool", "default": false},
        {"name": "co_quality_rating_of_child_care_facility", "entity": "person", "type": "number", "default": 0}
      ]
    }
  }
}
```

Input conventions: `entity: "person"` inputs apply to every child (one value
for all children is fine for v1); `entity: "spm_unit"` inputs apply once.
Inputs whose name ends in `_enrolled` (or `_is_in_re_determination_process`,
`_at_redetermination`) mean "already receiving the subsidy" and switch the
state to its redetermination income limit. Show them as one checkbox
labelled "Currently receiving this subsidy".

## Live household API

`POST https://api.policyengine.org/us/calculate` with body
`{"household": <situation>}`. The situation mirrors
`scripts/calculator.py::create_situation` exactly:

```jsonc
{
  "people": {
    "adult_1": {"age": {"2026": 35}, "employment_income": {"2026": 30000},
                "weekly_hours_worked_before_lsr": {"2026": 40}},
    "adult_2": {...employment_income 0...},              // only if 2 adults
    "child_1": {"age": {"2026": 3}, "childcare_hours_per_day": {"2026": 8},
                "childcare_days_per_week": {"2026": 5},
                "childcare_attending_days_per_month": {"2026": 22},
                "<person-level state input>": {"2026": "DCC_SACC"}}
  },
  "families": {"family": {"members": [all]}},
  "marital_units": {"marital_unit": {"members": [adults]}},
  "tax_units": {"tax_unit": {"members": [all]}},
  "spm_units": {"spm_unit": {"members": [all],
      "spm_unit_pre_subsidy_childcare_expenses": {"2026": charge * 12 * children},
      "meets_ccdf_activity_test": {"2026": true},
      "<spm-level state input>": {"2026": false},
      "il_ccap": {"2026": null}, "il_ccap_copay": {"2026": null}, ...   // every `outputs` entry set to null
  }},
  "households": {"household": {"members": [all], "state_code": {"2026": "IL"},
                 "county": {"2026": "COOK_COUNTY_IL"}}}
}
```

Response: `{"status": "ok", "result": {"spm_units": {"spm_unit": {"il_ccap": {"2026": 17784.0}, ...}}}}`.
Values for `2026` are **annual** sums, so monthly subsidy = value / 12 and
monthly copay = value / 12 * copay_factor (or * attending days when
`copay_factor == "days"`). Person-level copays come back under
`result.people.child_N` and must be summed.

Two person-level overrides are baked into `create_situation` and must be
mirrored: Maryland `md_ccs_provider_type = "LICENSED_CENTER"` (model default
`NONE` pays nothing), and Massachusetts `ma_ccfa_care_provider_type` is
`CENTER_BASED_CARE_EARLY_EDUCATION` for children under 5 and
`CENTER_BASED_CARE_SCHOOL_AGE` otherwise. A user-chosen value for the same
input wins.

## `policy_index.json` (from `policy_index.py`)

```jsonc
{
  "year": 2026,
  "states": {
    "IL": {
      "code": "IL", "name": "...", "program": "...",
      "parameter_root": "gov.states.il.dhs.ccap",
      "parameters_used": ["gov.states.il.dhs.ccap.copay.table_a.family_size_3", ...],
      "parameters": [
        {"path": "...", "label": "...", "description": "...", "unit": "/1" | "currency-USD" | "year" | null,
         "period": "year" | "month" | null,
         "values": {"2026-01-01": 0.85, "2026-07-01": 0.85},
         "references": [{"title": "...", "href": "https://..."}]},
        {"path": "...", "label": "...", "scale": [{"threshold": 0, "amount": 10}, ...], "references": [...]},
        {"path": "gov.states.tx.twc.ccs.payment", "label": "...", "group": true, "count": 24193,
         "sample": [{"path": "...", "value": 42.5}], "references": [...]}   // large rate tables are summarized
      ],
      "thresholds": {
        "1_two": {"income": 61000, "fpg_ratio": 2.233, "smi_ratio": 0.567,
                  "max_subsidy": 1517.0, "subsidy_at_zero_income": 0.0},
        ... or null when the household is never eligible
      }
    }
  }
}
```

`thresholds` are computed at the default charge level and give the highest
annual income at which the model still pays a positive subsidy.

## `impact.json` (from `microsim.py`, optional)

```jsonc
{
  "year": 2026, "dataset": "...populace_us_2024_year_2026.h5",
  "policyengine_version": null, "policyengine_us_version": "1.824.7",
  "assumed_charge_per_child_month": 1500, "min_sample_units": 30,
  "assumptions": ["..."],
  "national": {"eligible_children": 0, "eligible_families": 0, "potential_annual_subsidy": 0,
               "children_under_13": 0,
               "paid_care": {"eligible_children": 0, "eligible_families": 0, "annual_subsidy": 0, "children_in_paid_care": 0}},
  "states": {
    "IL": {
      "eligible_children": 0,          // headline: under-13s with working parents the model would pay if they used full-time care
      "eligible_families": 0,
      "potential_annual_subsidy": 0,   // upper bound if all of them used care at the assumed charge; not spending
      "children_under_13": 0,
      "eligible_share": 0.0,           // eligible_children / children_under_13
      "paid_care": {                   // subset of families reporting child care expenses in the CPS
        "eligible_children": 0, "eligible_families": 0, "annual_subsidy": 0,
        "children_in_paid_care": 0,
        "sample_units": 51,            // unweighted sampled units with paid care in the state
        "small_sample": true           // sample_units < min_sample_units: show as unreliable
      }
    }
  }
}
```

The page must render a clear "not yet computed" state when the file is
missing or has no `states`. Headline map/ranking use `eligible_share` and
`eligible_children`; the paid-care subset is a secondary view that greys or
flags states where `small_sample` is true.
